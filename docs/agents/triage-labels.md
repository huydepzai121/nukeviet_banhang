# Triage labels

The tracker is local markdown. The `Status:` line uses these role strings as-is:

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`

`done` and `skipped` are completion states already used by tickets in this repo. `skipped` means the owner told us not to do that ticket; it does not block later tickets.
