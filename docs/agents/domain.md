# Domain Docs

Single-context repo.

## Before exploring, read these

- `GLOSSARY.md` at the repo root
- `docs/adr/` for decisions that touch the area you are about to change

Use the glossary's words. The words it says to avoid (danh mục, SKU, coupon, guest, user) stay out of new titles, tests, and docs.

If an output contradicts an ADR, say so explicitly instead of quietly overriding it.
